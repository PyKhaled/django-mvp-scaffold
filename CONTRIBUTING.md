# Contributing

Use Python 3.12 and follow the [setup guide](docs/getting-started/index.md).
The [development guide](docs/guides/development.md) lists commands, test boundaries,
and review expectations.

Open a focused issue for a bug or proposed feature, then submit a focused PR.
Include the behavior before/after, meaningful regression tests, configuration or
migration implications, documentation updates, and actual validation results.
Use descriptive branches and Conventional Commit-style messages.

Never include credentials, production data, or private ticket/password-reset URLs.
Report vulnerabilities through [SECURITY.md](SECURITY.md), not public issues.
Contributions must preserve applicable third-party notices.
